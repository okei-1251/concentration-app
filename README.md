# 【協力求！】音源による集中力への影響検証用App

---

## 概要
こんにちは！現在私は高校の探究活動で、「音源が集中力に与える影響」というテーマについて探究しています。

このアプリでは、検証対象である音源のをBGMとしての利用や、集中力テストを行うことできます。

正直、検証の母数が全然足りていない現状です...ご協力をお願いします!!

- **公開URL:** [https://okei-1251.github.io/concentration-app/](https://okei-1251.github.io/concentration-app/)

---

## 検証手順
1. [URL](https://okei-1251.github.io/concentration-app/)からアプリにアクセス  
2. ログインIDを入力
3. 基準値測定のため集中力テストを実行
4. 音源を選択し10分以上BGMとして利用する
5. 集中力テストを再度実行  
6. 終了後、フォームからフィードバックを送信
